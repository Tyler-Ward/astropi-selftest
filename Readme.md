Astropi selftest program
========================

This repo contains a modified version of the astropi selftest program contained in [The MK2 case build guide](https://projects.raspberrypi.org/en/projects/astro-pi-flight-case-mk2/)

The original source is a zip file contained in the [source repo](https://github.com/raspberrypilearning/astro-pi-flight-case-mk2) which was licenced under CC-BY-SA-NC (see licence file)

This version has been modified to fix various items that no longer work due to software changes since the original version was released.
